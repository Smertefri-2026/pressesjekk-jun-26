# PresseSjekk – Kampanjelogg

*Enkel logg for kampanjer, resultater og læring. Fyll inn én rad/blokk per kampanje. Ikke legg inn oppdiktede resultater – kun reelle, registrerte tall. Tomme felt er greit inntil data finnes.*

## Slik brukes loggen

- Kopiér malen under for hver nye kampanje.
- Fyll ut det som er kjent ved oppstart, og oppdater tallene etter publisering.
- «Godkjent av» skal alltid fylles ut før publisering.
